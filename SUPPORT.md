# Support / Soporte

## English

Start with the [installation guide](docs/en/installation.md),
[user guide](docs/en/user-guide.md), and [troubleshooting notes](README.md#troubleshooting-and-current-limits).
For reproducible bugs or feature requests, use the repository's
[issue forms](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose).
Include your plugin version, Omarchy version, expected and actual behavior,
steps to reproduce, and redacted logs. Do not post secrets, tokens or private
configuration exports. For vulnerabilities, use the private reporting route in
[SECURITY.md](SECURITY.md).

The project is currently in development. Volunteer maintainers cannot promise
an individual response time. If you want to support maintenance, see
[GitHub Sponsors](https://github.com/sponsors/PuroDelphi) or
[PayPal](https://www.paypal.com/donate/?hosted_button_id=KBAUBYYDNHQNQ).

## Español

Empieza por la [guía de instalación](docs/es/installation.md),
la [guía de uso](docs/es/user-guide.md) y la [solución de problemas](README.md#troubleshooting-and-current-limits).
Para fallos reproducibles o ideas, usa los
[formularios de incidencias](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose).
Incluye las versiones del plugin y de Omarchy, el resultado esperado y real,
pasos para reproducir y registros sin datos sensibles. No publiques secretos,
tokens ni exportaciones privadas. Para vulnerabilidades, usa el canal privado
indicado en [SECURITY.md](SECURITY.md).

El proyecto está en desarrollo. Los mantenedores voluntarios no garantizan un
tiempo de respuesta. Puedes apoyar su mantenimiento mediante
[GitHub Sponsors](https://github.com/sponsors/PuroDelphi) o
[PayPal](https://www.paypal.com/donate/?hosted_button_id=KBAUBYYDNHQNQ).
