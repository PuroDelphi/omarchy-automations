# Security policy / Política de seguridad

## English

Omarchy Automations can receive network events and execute reviewed OS actions.
If you find a vulnerability, use GitHub's private
[Report a vulnerability](https://github.com/PuroDelphi/omarchy-automations/security/advisories/new)
form. Include the affected version, reproduction steps, impact, and a minimal
proof of concept. Please do not disclose exploit details in public issues or
pull requests. For non-sensitive bugs, use the [issue forms](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose).

The current `0.1.0-dev` preview is supported on Linux amd64 with Omarchy
Quattro. It is not a production-ready security guarantee. Security fixes are
handled in the current development line; there is no supported older release
branch. See the [security guide](docs/en/security.md) for capability grants,
webhook exposure, credential storage and action isolation.

## Español

Omarchy Automations puede recibir eventos de red y ejecutar acciones del
sistema operativo que hayan sido revisadas. Si encuentras una vulnerabilidad,
usa el formulario privado de GitHub
[Report a vulnerability](https://github.com/PuroDelphi/omarchy-automations/security/advisories/new).
Incluye versión afectada, pasos de reproducción, impacto y una prueba mínima.
No publiques detalles de explotación en incidencias ni solicitudes públicas.
Para errores sin información sensible, usa los
[formularios de incidencias](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose).

La versión previa `0.1.0-dev` se admite en Linux amd64 con Omarchy Quattro y no
constituye una garantía de seguridad para producción. Las correcciones se
aplican a la línea de desarrollo actual; no existe una rama anterior con
soporte. Consulta la [guía de seguridad](docs/es/security.md).
