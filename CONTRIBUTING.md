# Contributing / Contribuir

## English

Thank you for helping improve Omarchy Automations. Before a large change,
open a [feature request](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose)
to agree on scope. Small fixes can go directly to a pull request.

1. Read the [development guide](docs/en/development.md) and the
   [architecture](docs/en/architecture.md).
2. Keep the default UI and primary documentation in English; update the
   corresponding Spanish text when changing user-visible behavior.
3. Explain the behavior and security implications, especially for webhooks,
   credentials, permissions and command execution. Add focused tests when the
   behavior needs them and run the relevant checks from the development guide.
4. Include a concise description and validation evidence in the pull request.
   Never include tokens, private logs or real personal data.

All participation follows the [Code of Conduct](CODE_OF_CONDUCT.md). Report
security problems through [private vulnerability reporting](SECURITY.md).
Contributions are provided under the project's [MIT license](LICENSE).

## Español

Gracias por mejorar Omarchy Automations. Antes de un cambio grande, abre una
[solicitud de funcionalidad](https://github.com/PuroDelphi/omarchy-automations/issues/new/choose)
para acordar el alcance. Las correcciones pequeñas pueden ir directamente a un
pull request.

1. Lee la [guía de desarrollo](docs/es/development.md) y la
   [arquitectura](docs/es/architecture.md).
2. Mantén la interfaz y documentación principal en inglés; actualiza el texto
   equivalente en español cuando cambie el comportamiento visible.
3. Explica el comportamiento y las implicaciones de seguridad, especialmente
   para webhooks, credenciales, permisos y comandos. Añade pruebas enfocadas
   cuando sean necesarias y ejecuta las verificaciones pertinentes.
4. Describe el cambio y cómo lo verificaste. No incluyas tokens, registros
   privados ni datos personales reales.

Se aplica el [Código de conducta](CODE_OF_CONDUCT.md). Reporta problemas de
seguridad por el [canal privado](SECURITY.md). Las contribuciones se publican
con la [licencia MIT](LICENSE).
